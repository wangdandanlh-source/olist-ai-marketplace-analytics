# Limitations

1. Seller Match 45.13%: downstream sellers are selected, not all deals.
2. Low Repeat: about 97% one-order customers; frequency-based RFM has limited resolution.
3. Observation Censoring: core and mature windows reduce, but do not eliminate, coverage risk.
4. No acquisition cost: no CAC, ROI or best-channel claim.
5. Association is not causation: decomposition and adjusted OR do not identify intervention effects.
6. Review Self-selection: written-review users are not all buyers.
7. Review Timing: after-delivery uses answer timestamp; selection changes denominators.
8. No Human Gold Set: no validated classification performance metric.
9. Mixed / Other 62.70%: cluster topics have substantial semantic ambiguity.

No experiment has been run. Proposals and planning parameters are hypotheses; the report contains no claimed lift, revenue improvement or forecasted ROI.
